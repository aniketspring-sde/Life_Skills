

## Question 1: Which point(s) were new to you?


- Over-communicating about unexpected problems: I learned that if requirements change, the implementation takes longer, or there is a technical issue, I should inform the relevant team members instead of waiting.
- Asking questions properly: Instead of simply saying that something is not working, I should clearly explain the problem, mention what I have already tried, and provide screenshots or code when required.
- Using group communication: Communicating through common team channels is often better than private messages because everyone who is relevant can stay informed.
- Protecting focused work time: I learned that avoiding unnecessary notifications and distractions is important for maintaining concentration during programming.

## Question 2: Which area do you think you need to improve on? What are your ideas to make progress in that area?

I think I need to improve my communication, especially when I am stuck or facing an unexpected problem.

Sometimes I may spend too much time trying to solve a problem on my own without informing the team. To improve this, I will:

- Clearly explain the problem before asking for help.
- Mention the approaches I have already tried.
- Share relevant error messages, screenshots, or code snippets.
- Inform the team early if a task is taking longer than expected.
- Use the appropriate group channel for communication.
- Ask questions instead of staying stuck for a long time.

This will help me communicate more effectively, avoid unnecessary delays, and keep the team informed about my progress.
